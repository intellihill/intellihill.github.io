PARA에서 모든 메모가 Archives로 가는 것이 아니다. **Projects만 완료되면 Archives로 간다.**

## 폴더별 운명

| 폴더 | Archives로 가나? | 이유 |
|------|------------------|------|
| **Projects** | ✅ 완료되면 감 | 끝이 있는 작업 |
| **Areas** | ❌ 계속 유지 | 삶의 영역 (끝 없음) |
| **Resources** | ❌ 계속 유지 | 지식은 축적됨 |

## 전체 흐름

```
Inbox
  │
  ├─► Projects/ ───완료───► Archives/
  │
  ├─► Areas/ ───────────► (계속 유지)
  │
  └─► Resources/ ────────► (계속 유지, 지식 축적)
```

## 예시

```
Projects/블로그 글 작성  →  완료  →  Archives/2025/
Areas/건강              →  평생 유지 (Archives 안 감)
Resources/cpp/포인터    →  계속 참고 (Archives 안 감)
```

## Resources가 Archives로 가는 경우

**더 이상 관심 없는 주제**일 때만:

```
Resources/요리 레시피  →  요리에 흥미 잃음  →  Archives/
Resources/게임 공략    →  그 게임 안 함     →  Archives/
```

하지만 대부분의 지식 메모는 **계속 참고되므로 Resources에 유지**.

## 정리

```
✅ Projects = 완료되면 Archives
✅ Areas = 계속 유지 (삶의 영역)
✅ Resources = 계속 유지 (지식 축적)
```
