제텔카스텐의 핵심은 메모를 **연결**하여 새로운 아이디어를 발견하는 것이다.

## 3가지 원칙

### 1. 원자성 (Atomicity)
```
1메모 = 1아이디어

❌ "C++ 포인터 총정리"
✅ "포인터 선언 시 *는 타입 지정자다"
```

### 2. 연결성 (Connectivity)
```
모든 메모는 최소 1개 이상 링크

[[관련 메모]] - 연결 이유
```

### 3. 자기 언어 (Own Words)
```
원문 복사 ❌
내 언어로 재구성 ✅
```

## 연결의 힘

```
단일 메모: 하나의 정보
     ↓
연결된 메모: 새로운 통찰

A + B = C (새로운 아이디어)
```

## 제목 작성법

```
❌ 명사형: "포인터"
❌ 주제형: "포인터 정리"
✅ 문장형: "포인터 선언 시 *는 역참조가 아니라 타입 지정자다"
```

완전한 문장 제목은:
- 검색하기 쉬움
- 아이디어가 명확함
- 연결할 때 맥락 파악 용이
