PARA는 정보를 "주제"가 아닌 "행동 가능성"으로 분류하는 시스템이다.

## PARA 구조

| 폴더 | 정의 | 행동 가능성 |
|------|------|-------------|
| **P**rojects | 목표+기한 있는 작업 | 지금 당장 |
| **A**reas | 지속 관리 영역 | 꾸준히 |
| **R**esources | 참고 자료 | 언젠가 |
| **A**rchives | 완료/비활성화 | 더 이상 없음 |

## 폴더 구조

```
0. Inbox/       → 모든 메모의 시작점
1. Projects/    → 블로그 글 작성, 이직 준비
2. Areas/       → 건강, 재정, 커리어
3. Resources/   → 프로그래밍, 독서 노트
4. Archives/    → 완료된 프로젝트
```

## 분류 질문

```
이 메모가...

1. 현재 프로젝트 관련? → Projects
2. 지속 관리 영역? → Areas
3. 나중에 참고할 자료? → Resources
4. 더 이상 필요 없음? → Archives
```

## 핵심 원칙

- **Inbox는 비워야 한다**: 일일 리뷰로 정리
- **Projects는 완료된다**: 끝나면 Archives로
- **Areas는 유지된다**: 삶의 책임 영역
- **Resources는 축적된다**: 지식 라이브러리
