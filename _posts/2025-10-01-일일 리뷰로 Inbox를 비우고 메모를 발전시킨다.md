메모 시스템의 핵심은 **정기적인 리뷰**다. Inbox가 쌓이면 시스템이 무너진다.

## 리뷰 주기

| 주기 | 시간 | 작업 |
|------|------|------|
| **일일** | 5분 | Inbox 정리, Fleeting → Permanent |
| **주간** | 30분 | 고아 메모 연결, Projects 점검 |
| **월간** | 1시간 | PARA 정비, Archives 이동 |

## 일일 리뷰 (5분)

```
1. Inbox 열기
2. 각 메모 검토:
   - 발전시킬 가치? → Permanent로 변환
   - 가치 없음? → 삭제
3. 변환한 메모 PARA 위치로 이동
4. 링크 추가
```

## 주간 리뷰 (30분)

```
1. Inbox 완전히 비우기
2. 이번 주 작성 메모 검토
3. 링크 없는 고아 메모 찾기 → 연결
4. Projects 진행 상황 점검
5. 다음 주 계획
```

## 월간 리뷰 (1시간)

```
1. PARA 구조 점검
2. 완료된 Projects → Archives
3. Areas 목표 달성도 확인
4. Resources 정리 (오래된 자료)
5. 한 달 회고 작성
```

## Inbox가 쌓이면?

```
Inbox 10개 이상 → 위험 신호

원인:
- 리뷰 스킵
- 캡처만 하고 정리 안 함

해결:
- 지금 당장 30분 투자해서 정리
- 3개월 이상 방치된 메모는 삭제
```
