PARA에서 Archives는 중간 단계가 아니라 **최종 보관함**이다.

## 올바른 흐름

```
Inbox (캡처)
    │
    ▼ 일일 리뷰
    │
    ├─► Projects/  ← 현재 진행 중인 프로젝트 관련
    ├─► Areas/     ← 지속 관리 영역 (건강, 커리어 등)
    └─► Resources/ ← 참고 자료, 지식 (대부분 여기)

         │
         ▼ 나중에 완료/비활성화되면
         │
      Archives/    ← 완료된 프로젝트, 관심 없는 자료
```

## 흔한 오해

```
❌ Inbox → 참고 중 → Archives → 완성 → Resources
✅ Inbox → Projects/Areas/Resources → (완료 시) Archives
```

**Archives는 거쳐가는 곳이 아니라 끝나는 곳이다.**

## 각 폴더의 역할

| 폴더 | 들어가는 것 | 예시 |
|------|-------------|------|
| **Inbox** | 모든 새 메모 (임시) | 떠오른 생각 |
| **Projects** | 진행 중 프로젝트 | 블로그 글 작성 |
| **Areas** | 지속 관리 영역 | 건강, 재정, 커리어 |
| **Resources** | 참고 지식/자료 | C++ 포인터, 독서 노트 |
| **Archives** | 끝난 것들 | 완료된 프로젝트 |

## 예시 1: C++ 공부 메모

```
1. 공부하다 의문 발생
   → 0. Inbox/ 에 빠르게 캡처

2. 일일 리뷰에서 정리
   → 3. Resources/cpp/ 로 이동

3. 끝! (Archives 아님, 계속 참고할 지식)
```

## 예시 2: 프로젝트 완료

```
1. "블로그 글 작성" 프로젝트 진행
   → 1. Projects/블로그 글 작성/

2. 블로그 글 완료!
   → 4. Archives/2025/ 로 이동
```

## 핵심 질문

Inbox 메모를 정리할 때:

```
Q: 현재 프로젝트 관련?
   → Projects/

Q: 지속적으로 관리하는 영역?
   → Areas/

Q: 나중에 참고할 지식?
   → Resources/

Q: 더 이상 필요 없음?
   → 삭제 또는 Archives/
```
